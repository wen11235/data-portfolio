Try it: use the dropdown on the revenue chart to filter by country, toggle the product chart between revenue and units sold, hover over the map for exact country-level revenue, or click a legend entry on the segment chart to isolate it.

Why static, not Streamlit/Dash

A fully cross-filtered dashboard (click a country, every chart updates) usually means Dash or Streamlit — which need a live Python process, not something GitHub Pages can host. This version trades that for filters/toggles built with Plotly's client-side updatemenus — genuinely interactive (hover, zoom, dropdown filters, legend isolation), zero backend, works the instant the page loads. The build notebook generates each chart as a static HTML fragment that gets embedded directly into this page.
